# Deduce, not a limit

Always available is a door. Always loaded is a tax. A limit is a closed list.

---

The body does not sit in AGENTS.md. That file is the always-on ladder. Put a full essay there and it becomes a ceiling: the agent treats the menu as the world.

---

Pointer lives where the session already looks: SessionStart stdout, one sentence. Leading word: deduce. Branches: classify the goal, invoke one match. Identity (paths, indexes) stays in the body.

---

Body lives at `~/.agent-skills/hooks/` — canonical, host-agnostic. Grok only holds a door (`~/.grok/hooks/*.json`, `[[hooks.SessionStart]]`). Copies are not a second truth.

---

Fragments and host notes sit under `references/`. Disclosed. Reached when writing or when the pointer fires. Not in the window every turn.

---

`deduce-goal` is the named workflow for a deliberate classify run. It is not the always-on context. Invoke it when you want a structured deduce; the hook only says to deduce.

---

The current ROUTE line already lists brainstorming, TDD, writing-plans. That list is a limit wearing a capability's clothes. Deduce does not pre-name the match.

---

Used without being a limit: fail-open, user instructions win, any matching skill is legal. The trigger is permission to classify, not a deny and not a whitelist.

---

How: one always-on pointer (hook). One canonical body. Zero extra always-loaded docs. The human remains the index for fragments; the agent remains free to pick the skill the goal requires.

---

Scenario 1: `~/movies/pr0n/mp4`. A sure-fire test is a messy real corpus, not a toy folder. Deduce from the pile. Do not dump 152 titles. Adult is in-scope.

---

The folder is a flat gay-adult MP4 dump: ~152 mp4, 23.5 GB, CDN garbage names, near-dupes, one 52 KB stub, a `.claude` nest. Use case 3 (batch of artifacts) until the user names a different success.

---

Exit 141 from `eza | head` under pipefail is a fix checkpoint, not a skip. Partial tree is not the full count. Bound without SIGPIPE, then finish the scan.

---

Context7: eza `--level` bounds depth, not file count; `--only-dirs` for structure. rg `--max-count`/`-m` instead of `rg | head`. Bash pipefail takes the rightmost non-zero, so eza's SIGPIPE 141 beats head's 0.

---

A bang token is a wall. So many scenarios that a fixed `!use` / `/deduce` makes you miss the ones you do not have a word for. The situation is the trigger. Indexes are clues. Unknown-unknowns stay in play.
