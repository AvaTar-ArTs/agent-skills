# Checkpoint template (new note, never an overwrite)

Frontmatter: `name`, `description` (one line: scope, what changed vs the previous pass), `metadata.type: project`.
Link the previous pass and earlier selves with `[[note-name]]`.

1. **Method (MEASURED):** transcript path and size, extractor/version, totals (lines, tool calls by name, typed prompts, queued prompts, errors, classifier blocks), what you did NOT read.
2. **Chronology:** one line per phase with UTC times and the user's words at each correction.
3. **Corrections to my own earlier claims:** table of claim, result, evidence. Put false positives and discarded metrics here.
4. **Newly found:** items the earlier pass missed, each with how you found it.
5. **Scorecard vs the user's standing rules and earlier selves:** rule, earlier result, this pass, evidence. Include repeats and improvements.
6. **Comparison with earlier selves:** convergences, divergences, sources (other checkpoints, decision rows, other hosts).
7. **Open items:** nothing decided here; name the first recommended action.

After saving: one MEMORY.md index line, one Engram append (no secrets), a decision row only for decided items.
